## 💎 Liquid Glass Design Architecture

This project features bespoke CSS `.liquid-glass` optics with dynamic backdrop blur, luminosity blending, and multi-stop gradient mask borders:

```css
.liquid-glass {
  background: rgba(255, 255, 255, 0.01);
  background-blend-mode: luminosity;
  backdrop-filter: blur(4px);
  -webkit-backdrop-filter: blur(4px);
  border: none;
  box-shadow: inset 0 1px 1px rgba(255, 255, 255, 0.1);
  position: relative;
  overflow: hidden;
}
```

## 🚀 Sections & Features

1. **Section 1 — Full-Viewport Video Hero:**
   - Seamless looping background video with vanilla JS `requestAnimationFrame` 500ms opacity crossfade.
   - Liquid Glass floating navbar pill with brand identity and quick links.
   - High-contrast Instrument Serif typography: *"Know it then all."*
   - Interactive newsletter input pill and social icons dock.
2. **Section 2 — About Us:**
   - Scroll-triggered Framer Motion viewport reveal (`useInView`).
   - Radial luminescence overlay and dual-weight serif text structure.
3. **Section 3 — Featured Video:**
   - Aspect-video cinematic player with rounded-3xl geometry.
   - Glassmorphic card overlay (*"Our Approach"*) with hover motion buttons.
4. **Section 4 — Philosophy (Innovation x Vision):**
   - Two-column responsive layout with 4:3 video player and dual strategic text blocks.
5. **Section 5 — Services (What We Do):**
   - High-touch 2-card interactive grid (*"Research & Insight"* + *"Design & Execution"*).
   - Fluid group-hover zoom scaling and arrow button micro-interactions.
